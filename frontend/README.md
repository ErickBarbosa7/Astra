# Astra Frontend

Interfaz de usuario de Astra. Construida con React + Vite + TypeScript + Tailwind CSS v4 (estilo Bento UI).

## Comandos

```bash
npm install
npm run dev        # http://localhost:5173
npm run build
npm run lint
npm run format
```

El servidor de desarrollo hace proxy de `/api` hacia el backend en `http://localhost:4000`.

Ver el `README.md` de la raíz para la puesta en marcha completa.
